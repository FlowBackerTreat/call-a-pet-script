FAQ

Common questions

Quick answers about compatibility, safety, and configuration.

Which Windows versions are supported? +
Call A Pet Script runs on Windows 10 and Windows 11 (64-bit). It needs no external runtime — the executable is self-contained, so there is nothing else to install.
Is the script free and open source? +
Yes. The project is completely free and the full source code is publicly available on GitHub. You can read, audit, and modify every part of it, and there are no premium tiers or locked features.
How does the chat-triggered call command work? +
You define a trigger phrase in the settings panel. When that phrase appears in chat, the script summons your active pet to your position. A configurable cooldown prevents accidental or repeated triggers during fast typing.
Can I change the hotkeys after setting them up? +
Absolutely. Every hotkey is rebindable at any time from the control panel. You can also clear a binding entirely if you prefer to summon pets using only the chat command.
